# Third-party software

## HandBrakeCLI

The Windows build bundles HandBrakeCLI 1.11.2 from the HandBrake project and
uses its x265 encoder for Compact Mode.

- Project: https://handbrake.fr/
- Source: https://github.com/HandBrake/HandBrake/tree/1.11.2
- Binary archive: `HandBrakeCLI-1.11.2-win-x86_64.zip`
- Archive SHA-256: `80bfe8d5f5d11cc3ef76b834add3ed4e82dee6523ffeb435c283f88b1a21f09d`

HandBrake's copyright and license files are distributed beside the executable
under `resources/binaries/handbrake/doc`.
